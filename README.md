# Algorithmic Hiring Simulation

## AISE 26 Solo Capstone Project
**Sarina Parrish**

---

## Project Overview

This project explores how personality-based AI hiring systems can influence workforce diversity over time.

Modern hiring platforms increasingly rely on algorithmic screening tools and personality assessments to evaluate candidates using traits like the Big Five personality model. While these systems are often presented as objective, small biases in how traits are weighted may compound across many hiring decisions and produce larger systemic disparities.

This capstone models those effects using an agent-based simulation built in Python.

---

## Core Research Question

How do trait-weighting choices in AI hiring algorithms affect workforce composition over time, and under what conditions do small individual scoring biases produce larger systemic outcomes?

---

## MVP Features

Phase 1 focuses on building a complete simulation pipeline including:

- Synthetic candidate generation
- Big Five personality vectors
- Configurable hiring scoring functions
- Multi-round hiring simulation
- Workforce composition tracking
- Diversity metrics and visualizations
- Experiment comparison between different scoring approaches

---

## Planned Phase 2 Features

Potential future additions include:

- Feedback loops where workforce composition influences future hiring
- Blind screening interventions
- Additional scoring models
- Sensitivity analysis
- Comparison to published hiring audit studies
